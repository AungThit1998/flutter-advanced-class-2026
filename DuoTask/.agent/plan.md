# Project Plan

Build a To-Do List app named DuoTask where users can add, check off, and delete tasks. The app must be large-screen friendly using a 2-pane layout (adaptive guidelines), with a list of tasks on the left and an editor view on the right. It must strictly follow Material Design 3 (M3) and Android UX guidelines, including Full Edge-to-Edge Display and a vibrant, energetic color scheme.

## Project Brief

# Project Brief: DuoTask

DuoTask is a modern, high-performance To-Do List application designed for productivity on both mobile and large-screen devices. It leverages an adaptive 2-pane layout to provide a seamless multitasking experience.

## Features
- **Task Management**: Create, mark as complete, and delete tasks with a clean, intuitive interface.
- **Adaptive 2-Pane Layout**: Optimized for tablets and large screens, featuring a list of tasks on the left and a detailed editor/viewer on the right.
- **Material Design 3 UI**: Strictly follows M3 guidelines with a vibrant, energetic color scheme and full edge-to-edge display.
- **Interactive Editor**: Dedicated view for focusing on task details and quick modifications.

## High-Level Technical Stack

- **Kotlin**: The primary programming language for modern Android development.
- **Jetpack Compose**: For building a reactive and declarative UI.
- **Compose Adaptive**: To implement the 2-pane layout for large-screen support.
- **Kotlin Coroutines**: For handling asynchronous operations and background tasks.
- **Jetpack ViewModel**: To manage UI-related data in a lifecycle-conscious way.
- **KSP (Kotlin Symbol Processing)**: Used for efficient code generation.
